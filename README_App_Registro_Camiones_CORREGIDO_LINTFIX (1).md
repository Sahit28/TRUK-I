# App Registro Camiones 🚚

Aplicación web para registrar el ingreso y salida de camiones. Desarrollada con **React** en el frontend y **Node.js + Express** en el backend.

## 📦 Tecnologías utilizadas

- Frontend: React, Axios, CSS
- Backend: Node.js, Express
- Otros: JSON (configuración)

## 📸 Capturas de pantalla

*Aquí se pueden incluir imágenes del funcionamiento de la app*

## 🚀 Funcionalidades

- Registro de camiones (formulario)
- Visualización de registros en una tabla
- Estilos visuales: logo, pestañas, fondo personalizado

## 🛠️ Instalación y ejecución

```bash

# Backend

cd backend
npm install
npm start

# Frontend

cd frontend
npm install
npm start
```bash
